# Lab evidence checklist

Add screenshots captured directly from the configured VirtualBox and Kali environment when they are available.

Recommended captures:

1. **NAT Network settings** – show the NAT Network name and IPv4 prefix `10.0.0.0/24`.
2. **Kali VM network settings** – show Adapter 1 enabled and attached to the intended NAT Network.
3. **Kali terminal verification** – show the assigned address, default route and successful connectivity/DNS checks.
4. **VM integration settings** – show Shared Clipboard and Drag and Drop set to Bidirectional.
5. **Shared folder settings** – show the host Downloads directory shared with the name `downloads` and Auto-mount enabled.

Use screenshots from the actual lab machine. Do not use reference diagrams, mock-ups or recreated interface images as proof that a setting was applied. Hide personal paths, usernames or other private information before publishing screenshots.
