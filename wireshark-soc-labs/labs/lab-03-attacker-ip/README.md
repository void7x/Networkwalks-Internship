# Lab 03 — Identify the Attacker's IP

**Assessment result:** 90/100

## Objective

Practise using packet-level evidence to distinguish a scanning source from its target and interpret TCP port-scan behaviour.

## Investigation areas shown on the result card

- Capturing network traffic.
- Isolating SYN packets.
- Identifying the suspected attacker and target.
- Reviewing the source port and the ports being probed.
- Distinguishing open-port and closed-port responses.
- Classifying the scan activity.

## What I learned

A sequence of connection attempts can reveal scanning behaviour. The direction of SYN packets, source and destination fields, and the target's responses help an analyst reason about which host initiated the activity and which ports responded.
