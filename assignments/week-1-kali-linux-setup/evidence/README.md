## Evidence handling

- Use screenshots captured directly from the configured Windows host, VirtualBox and Kali VM.
- Do not create mock screenshots or use online images as proof of completion.
- Do not expose passwords, personal documents, unrelated Downloads contents, private Windows paths or unnecessary identifiers.
- Crop screenshots to the relevant settings or terminal output.
- The final snapshot screenshot should only be added after the snapshot has actually been created.
